# Interest Rates Documentation

This folder contains interest rate schedules for the Bank's deposit and loan products.

---

## Planned Documents

| Document | Description | Status |
|---|---|---|
| deposit-interest-rates.md | Interest rates for Savings, FD, RD, and Tax Saver deposits | Planned |
| loan-interest-rates.md | Interest rates for all loan products | Planned |

---

## Scope

Documents in this folder provide:

- Current interest rate tables
- Rate tiers based on amount, tenure, and customer segment
- Special rates for senior citizens
- Benchmark rate references (Repo Rate, MCLR, EBLR)
- Historical context where relevant
- Effective dates

---

## Important Notes

- Interest rates change frequently and must be reviewed regularly
- All rate documents must include `last_updated` and `effective_date` in metadata
- These documents are strong candidates for dynamic data sources in the future RAG system
