## Scope

Documents in this folder cover:

- Available support channels (branch, phone, email, chat, social media)
- Complaint registration process
- Complaint tracking and reference numbers
- Resolution timelines and SLAs
- Escalation levels (Branch → Nodal Officer → Banking Ombudsman)
- RBI Integrated Ombudsman Scheme
- Feedback and satisfaction processes
