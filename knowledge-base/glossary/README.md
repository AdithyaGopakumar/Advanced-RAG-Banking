## Purpose

The glossary serves multiple functions:

1. **Customer Reference** — Helps customers understand unfamiliar banking terms
2. **Consistency** — Provides the canonical definition for terms used across all documents
3. **AI Retrieval** — Enables the RAG system to answer "What does X mean?" queries
4. **Onboarding** — Helps new contributors use terminology consistently

---

## Glossary Format

Each entry follows this structure:

```markdown
### Term Name

**Also known as**: [Alternative names or abbreviations]

[Clear, customer-friendly definition in 1–3 sentences]

**Example**: [Optional real-world usage example]

**Related terms**: [Links to related glossary entries]
```
