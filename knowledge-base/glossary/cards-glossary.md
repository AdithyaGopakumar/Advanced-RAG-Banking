# Cards Glossary

## PIN
**Short Definition**: A 4-digit code (ambiguous).

**Standard Definition**: AMBIGUOUS TERM. Can refer to ATM PIN (Debit/Credit Card), UPI PIN, or MPIN (Mobile App Login). Requires clarification: 'Is this the PIN for your card, or the app login?'

**Customer May Say**: "forgot my PIN", "my PIN is blocked"

**Synonyms**: Password, Secret Code

**Acronyms / Abbreviations**: Personal Identification Number

**Common Misspellings**: pinn, password

**Related Terms**: Authentication, MPIN, UPI PIN

**Confusable Terms**: OTP (One Time Password which expires, unlike a static PIN)
