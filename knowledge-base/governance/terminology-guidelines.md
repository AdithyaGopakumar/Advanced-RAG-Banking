# Terminology Guidelines

This document defines the approved banking terminology for the knowledge base. All contributors must use these terms consistently across every document.

---

## Purpose

Consistent terminology ensures:

1. **Clarity** — Customers always see the same term for the same concept
2. **AI Accuracy** — The RAG system can match queries to documents reliably
3. **Professionalism** — The knowledge base reads as a single, coherent publication
4. **Searchability** — Keyword-based search works consistently

---

## General Rules

1. **Use the approved term** — If a term is listed in this document, use exactly that term
2. **Spell out on first use** — Abbreviations must be spelled out on first use in each document
3. **Do not invent terms** — If you need a new term, propose it through the review process
4. **Do not mix terms** — Once a term is used, do not switch to a synonym later in the same document
5. **Capitalise product names** — Official product names are capitalised (e.g., "Savings Account")
6. **Do not capitalise generic terms** — Generic banking terms are lowercase (e.g., "interest rate")

## Approved Product Names

Use these exact names when referring to the Bank's products and services.

| Approved Term | Do NOT Use |
|---|---|

| Salary Account | salary a/c |

## Approved Banking Terms

### General Terms

| Approved Term | Definition | Do NOT Use |
|---|---|---|
| the Bank | Reference to the institution | we, our bank, the company |
| Account holder | Person who owns the account | account owner, customer (when specific) |
| Beneficiary | Person receiving a fund transfer | recipient, payee |
| Nominee | Person designated to receive account proceeds | inheritor, benefactor |
| KYC | Know Your Customer | identity check, verification |
| PAN | Permanent Account Number | PAN card number, tax ID |
| Aadhaar | Aadhaar number or Aadhaar card | Aadhar, Adhar, UID |
| Transaction | Any debit or credit to an account | txn, tx |
| Balance | Amount available in an account | funds, money in account |
| Minimum balance | Minimum amount required in an account | min balance, minimum amt |
| Passbook | Physical record of account transactions | bank book |
| Account statement | Record of transactions over a period | bank statement, statement of account |

### Interest and Rates

| Approved Term | Definition | Do NOT Use |
|---|---|---|
| Interest rate | Rate at which interest accrues | ROI (ambiguous) |
| Per annum (p.a.) | Per year | per year, annually (when stating rates) |
| MCLR | Marginal Cost of Funds Based Lending Rate | — |
| EBLR | External Benchmark Lending Rate | external rate |
| Repo Rate | RBI's benchmark lending rate | policy rate |
| Compound interest | Interest on interest | — |
| Simple interest | Interest on principal only | — |
| TDS | Tax Deducted at Source | tax deduction |

### Loan-Specific Terms

| Approved Term | Definition | Do NOT Use |
|---|---|---|
| EMI | Equated Monthly Instalment | monthly payment, instalment |
| Tenure | Duration of a loan or deposit | term, period (use tenure for consistency) |
| Processing fee | One-time fee charged when a loan is sanctioned | application fee, setup fee |
| Prepayment | Paying off a loan before the scheduled tenure | early repayment, pre-closure |
| Foreclosure | Complete prepayment of the remaining loan amount | full prepayment, loan closure |
| Collateral | Asset pledged as security for a loan | security, guarantee |
| Disbursement | Release of loan funds to the borrower | payout, fund release |
| Sanction | Approval of a loan application | approval (use sanction in formal context) |

### Card-Specific Terms

| Approved Term | Definition | Do NOT Use |
|---|---|---|
| Credit limit | Maximum amount that can be charged to a credit card | card limit, spending limit |
| Billing cycle | Period between two credit card statements | statement period |
| Minimum amount due | Minimum payment required on a credit card statement | minimum payment |
| Reward points | Points earned on credit card transactions | loyalty points, bonus points |
| CVV | Card Verification Value | security code (use CVV) |
| 3D Secure | Additional online transaction authentication | Verified by Visa, Mastercard SecureCode (use 3D Secure as the generic term) |

## Terms to Avoid

| Avoid | Reason | Use Instead |
|---|---|---|
| "Simply" or "Just" | Condescending | Remove or rephrase |
| "Easy" or "Effortless" | Marketing language | Remove or rephrase |
| "Best-in-class" | Marketing language | Remove |
| "State-of-the-art" | Marketing language | Remove |
| "Click here" | Non-descriptive link text | Use descriptive link text |
| "As mentioned above" | Breaks self-containment | Reference the specific section or document |
| "Please note that" | Unnecessary filler | Start with the information directly |
| "It should be noted" | Passive filler | State the information directly |
| "In order to" | Wordy | Use "To" |
| "At this point in time" | Wordy | Use "Currently" or "Now" |

---

## Adding New Terms

To add a new term to the approved list:

1. Propose the term in a pull request that updates this document
2. Include:
   - The proposed term
   - Its definition
   - Any terms it replaces
   - Rationale for the choice
3. Get approval from the Knowledge Base Owner and the relevant SME
4. Once approved, update all existing documents that use the old term
