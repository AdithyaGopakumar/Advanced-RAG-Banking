# Governance Documentation

This folder contains the standards, guidelines, and processes that govern how the knowledge base is created, maintained, and reviewed.

**Every contributor must read these documents before making changes to the knowledge base.**

## Reading Order for New Contributors

1. **Start here**: [repository-rules.md](repository-rules.md) — Understand the non-negotiable rules
2. **Then**: [style-guide.md](style-guide.md) — Learn the writing standards
3. **Then**: [documentation-standards.md](documentation-standards.md) — Learn the formatting standards
4. **Then**: [naming-conventions.md](naming-conventions.md) — Learn how to name things
5. **Then**: [terminology-guidelines.md](terminology-guidelines.md) — Learn the approved banking vocabulary
6. **Then**: [chunking-guidelines.md](chunking-guidelines.md) — Learn to write for AI retrieval
7. **Then**: [contribution-guide.md](contribution-guide.md) — Learn the submission workflow
8. **Finally**: [information-architecture-guide.md](information-architecture-guide.md) — Learn how to extend the KB
